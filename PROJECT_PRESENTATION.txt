PROJECT OVERVIEW

What is the Distributed Task Scheduler?

Content:

 PROJECT DESCRIPTION
  A full-stack web application for managing and distributing computational 
  tasks across multiple worker nodes with real-time monitoring and control.

KEY OBJECTIVES
  • Enable distributed processing of large-scale jobs
  • Provide role-based access control for different user types
  • Monitor system health and job progress in real-time
  • Ensure fault tolerance and automatic task retry

 USE CASES
  • Data processing pipelines
  • Image/video processing tasks
  • Machine learning model training
  • Batch job scheduling
  • Scientific computations

THREE-ACTOR ARCHITECTURE

Actor System Design

Content:

ACTOR 1: JOB SUBMITTERS (End Users)
  Authentication: Email + Password (Laravel Sanctum)
  Capabilities:
    ✓ Submit new jobs with custom parameters
    ✓ Monitor their own job progress
    ✓ View task execution logs
    ✓ Receive notifications on job completion
  Dashboard: User Dashboard with personal job view

 ACTOR 2: WORKER NODES (API Clients)
  Who: Distributed computing nodes (programs/scripts)
  Authentication: API Token (X-Worker-Token header)
  Capabilities:
    ✓ Register with the system
    ✓ Request pending tasks from job queue
    ✓ Execute tasks and report results
    ✓ Send heartbeat signals for health monitoring
  Access: API-only (no web interface)

 ACTOR 3: SYSTEM ADMINISTRATORS
  Authentication: Email + Password + Admin Flag
  Capabilities:
    ✓ View all jobs across all users
    ✓ Manage user accounts
    ✓ Monitor worker node health
    ✓ View system-wide statistics
    ✓ Handle system configuration
  Dashboard: Admin Dashboard with full system control

KEY FEATURES & TECHNOLOGY STACK

Features & Technologies

Content:

 CORE FEATURES

Job Management
  • Create, update, delete jobs
  • Real-time status tracking (Pending → Running → Completed/Failed)
  • Task breakdown and distribution
  • Automatic retry on failure
  • Progress monitoring with percentage completion

Worker Management
  • Dynamic worker registration
  • Health monitoring via heartbeats
  • Load balancing across workers
  • Worker status tracking (Active/Idle/Offline)
  • Task assignment optimization

User Management
  • Secure authentication with token-based auth
  • Role-based access control (RBAC)
  • User isolation (users see only their jobs)
  • Profile management
  • Activity logging

Real-Time Monitoring
  • Live dashboard updates
  • System statistics (jobs, workers, tasks)
  • Activity feed with recent events
  • Notification system
  • Performance metrics

 TECHNOLOGY STACK

Backend:
  • Laravel 11 (PHP 8.2+)
  • MySQL 8.0 Database
  • Laravel Sanctum (API Authentication)
  • RESTful API Architecture
  • Queue System for task distribution

Frontend:
  • Vue.js 3 (Progressive Framework)
  • Vite (Build Tool)
  • Pinia (State Management)
  • Tailwind CSS (Styling)
  • Axios (HTTP Client)
  • Chart.js (Data Visualization)
